PostgreSQL restore

Restore into a fresh database, verify it, then point the app at it:

pg_restore --clean --if-exists --no-owner \
  -d postgresql://USER@HOST/makrotik backups/FILE.dump
What is covered

Database backups cover accounts, file records, archive state, lifecycle rules, traffic events and the audit log. Uploaded bytes live in uploads/ and must be copied separately.
